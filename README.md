
Учебный проект интернет-магазина на React с функционалом корзины и поиска товаров.

Функциональность:

📱 Каталог товаров с карточками

🔍 Поиск товаров по названию

🛒 Корзина покупок

➕ Добавление/удаление товаров

🔢 Изменение количества товаров в корзине

💰 Подсчет общей стоимости

Технологии:

React

React Router DOM (навигация)

JavaScript (ES6+)

HTML/CSS

Структура:
/pages - страницы приложения (Main, About, Contacts, Cart)

/components - переиспользуемые компоненты (Navbar, Footer)
